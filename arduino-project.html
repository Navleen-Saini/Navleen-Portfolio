Autonomous Safety Robot

Project Description

I built an Arduino-based autonomous safety robot capable of detecting nearby obstacles using ultrasonic sensors. The robot continuously monitors distance data from the sensors while moving.

I wrote the control program in C++ so that when an obstacle is detected within a threshold distance, the robot automatically switches to an avoidance mode. In this mode the robot changes direction and navigates around the obstacle to prevent collisions.

This project demonstrates embedded programming, sensor integration, and basic autonomous navigation logic.

Technologies

  • Arduino
  • C++
  • Ultrasonic Sensors
  • Real-time control logic
